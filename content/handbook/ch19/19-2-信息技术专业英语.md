# 信息技术专业英语

> 零基础导读：本节题目围绕信息技术基础概念的英文表述，术语多来自网络、数据库、安全、云计算等方向。记住核心术语和它们的用途，就能应对大部分题目。

## 1. 概念与要点

信息技术专业英语要求掌握计算机与网络常用术语。考法与项目管理英语相同：填空、术语释义匹配和正误判断。

**网络与通信术语**：

| 中文 | 英文 | 备注 |
|---|---|---|
| 传输控制协议/网际协议 | TCP/IP | 互联网协议族 |
| 域名系统 | Domain Name System | DNS 解析域名 |
| 超文本传输协议 | HTTP / HTTPS | HTTPS 更安全 |
| 防火墙 | Firewall | 过滤网络流量 |

| 路由器 | Router | 三层设备 |
| 交换机 | Switch | 二层设备 |
| 负载均衡 | Load Balancing | 分发请求 |

**数据库与安全术语**：

| 中文 | 英文 | 备注 |
|---|---|---|
| 关系数据库 | Relational Database | 用表组织数据 |
| 主键 | Primary Key | 唯一且非空 |
| 外键 | Foreign Key | 建立表间关联 |
| 结构化查询语言 | SQL | SELECT/INSERT 等 |

**新兴技术**：cloud computing（云计算）、virtualization（虚拟化）、container（容器）、microservices（微服务）、big data（大数据）、IoT（物联网）、machine learning（机器学习）、blockchain（区块链）。

**常用句式**："Which of the following best describes ...?"、"The main purpose of X is to ..."、"X differs from Y mainly in that ..."。

## 2. 关键考点

> 💡 **关键考点**：
> 1. 网络协议与设备辨析：DNS 解析域名、DHCP 分配地址、防火墙过滤流量、负载均衡分发请求，不要张冠李戴。
> 2. 安全三概念：authentication 是认证验身份，authorization 是授权定权限，encryption 是加密保内容，三者常互相设干扰项。
> 3. 数据库基础：primary key 主键要唯一且非空，foreign key 外键引用别的表，SELECT 查询与 INSERT/UPDATE/DELETE 要分清。

## 3. 常见考法

- "_____ translates domain names to IP addresses." 选 DNS，干扰项常放 DHCP、VPN 等。
- "The main function of a firewall is to _____." 选 filter network traffic。
- 给英文定义选术语，如 "A unique identifier for each row" 对应 primary key。

常见坑：混淆 authentication 与 authorization；认为加密能保证数据可用性；把编译器说成可直接执行代码。

## 4. 速记

口诀：**DNS 查地址，防火墙挡流量，认证验身份，授权定权限，加密保机密。**
