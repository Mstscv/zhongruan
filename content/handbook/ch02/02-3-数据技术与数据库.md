# 数据技术与数据库

> 零基础导读：数据库为什么要分三层视图？SQL 语句又分成几大类？数据仓库和普通业务库差在哪？本节用三级模式、关系模型、SQL 分类和数据仓库特征四块内容，覆盖本章最密集的选择题考点。

## 1. 概念与要点

**三级模式与两级映像**。数据库系统划分为三层：

| 层次 | 别名 | 作用 |
|---|---|---|
| 外模式 | 用户模式、子模式 | 用户看到的局部逻辑视图 |
| 概念模式 | 模式 | 全体数据的全局逻辑结构 |
| 内模式 | 存储模式、物理模式 | 数据在磁盘上的存储与存取方式 |

两级映像：**外模式/模式映像**保证**逻辑独立性**（全局逻辑结构变了，改映像即可，应用少动）；**模式/内模式映像**保证**物理独立性**（存储结构变了，改映像即可，逻辑结构不变）。

**关系模型基本概念**。一张表叫**关系**，一行叫**元组**，一列叫**属性**，属性取值范围叫**域**。**主键**从候选键中选定，唯一标识元组且不能为空；**外键**是引用其他表主键的属性，用来建立表间联系。候选键是"能唯一标识元组的极小属性集"，超键允许含多余属性。

**SQL 语句分类**：

| 类别 | 作用 | 典型语句 |
|---|---|---|
| DDL | 定义结构 | CREATE、ALTER、DROP |
| DML | 操纵数据 | SELECT、INSERT、UPDATE、DELETE |
| DCL | 权限控制 | GRANT、REVOKE |

**数据仓库特征**：面向主题、集成的、相对稳定的（非易失）、随时间变化的。它是面向分析的，与面向事务的 OLTP 数据库相对。数据进入仓库前通常做 **ETL**（抽取、转换、加载）。

**大数据 4V**：**大量**（Volume）、**高速**（Velocity）、**多样**（Variety）、**价值**（Value，价值密度低但总价值大）。

## 2. 关键考点

> 💡 **关键考点**：
> 1. 两级映像对应两种独立性：外模式/模式 → 逻辑独立性；模式/内模式 → 物理独立性，选择题最爱交叉着问。
> 2. SQL 分类：CREATE/DROP 是 DDL，SELECT/UPDATE 是 DML，GRANT 是 DCL。
> 3. 数据仓库四特征（面向主题、集成、非易失、随时间变化）与 4V（大量、高速、多样、价值）不要混。

## 3. 常见考法

- 描述"内模式变了模式不变"，问体现哪种独立性；或反过来考逻辑独立性。
- 给一条 SQL，问属于 DDL、DML 还是 DCL。
- 问主键、外键、候选键、超键的区别，尤其"主键唯一且非空""主键可以是复合的"。
- 判断哪些是数据仓库特征，把"面向事务、高并发更新"这类 OLTP 特点排除掉。
- 问 4V 的具体含义，警惕用读音相近的词凑数。

常见坑：把逻辑独立性和物理独立性对调；认为一个表可以有多个主键；把 SELECT 划到 DDL；把"面向事务"当成数据仓库特征。

## 4. 速记

口诀：**"外模式见用户，内模式见磁盘；外模模式保逻辑，模式内模保物理。"**

| 术语 | 对应 |
|---|---|
| 元组 | 表中一行 |
| 属性 | 表中一列 |
| 主键 | 唯一且非空，选自候选键 |
| 外键 | 指向别的表的主键 |
