# 控制采购

> 零基础导读：合同签完不是就没事了。这一节讲合同执行过程中怎么盯住卖方履约、出问题怎么谈判和索赔、活干完了怎么正式关掉合同——控制采购管的就是"签约之后到关合同之前"的全过程。

## 1. 概念与要点

**控制采购**是管理采购关系、监控合同执行与绩效、按需变更并采取纠偏措施、关闭合同的过程。它贯穿采购执行与收尾，主要工具与技术有绩效审查、检查与审计、索赔管理、采购谈判和数据分析。

**绩效审查**：对照合同约定，检查卖方的进度、质量与成本表现，判断是否偏差、是否需要纠偏。它是日常监控的主要手段，输出卖方履约评价与纠偏建议。

**检查与审计**：由买方或买方委托的第三方实施，验证卖方工作过程与可交付成果是否符合合同要求。卖方自检不能代替买方的检查。

**工作绩效信息**的流向是常考的逻辑链：卖方提交绩效数据 → 买方对照采购计划与合同比较 → 形成**工作绩效信息** → 汇入项目整体绩效，用于项目报告与决策。注意：项目团队内部人员的绩效考核不进入采购绩效信息。

**索赔管理**：有争议的变更称为**索赔**，买卖双方均可提出。处理顺序是先核实事实、再按合同争议解决条款协商，协商不成的按约定提请调解、仲裁或诉讼。不能单方面拒付、停付或直接解约。

**采购谈判**（控制采购阶段）：用于解决履约分歧、澄清变更与索赔争议，目标是双方可接受的解决方案，结果同样要书面记录。

**合同变更**：必须按合同变更控制条款以书面形式提出并经双方批准，口头约定效力不足。变更涉及费用与工期影响的，应同步确认调整。

**结束采购**与**结束项目或阶段**的关系是高频考点：

- 结束采购针对**单个采购合同**：确认工作与可交付成果可按合同验收标准接受、完成结算、更新采购档案并关闭合同。
- 结束项目或阶段针对**整个项目**：应先把每个采购合同关闭，再结束项目或阶段；未关闭的采购会阻碍项目收尾。
- **采购审计**从采购规划到执行做结构化审查，总结经验教训，供本项目后续或其他项目使用，不等于财务审计。

## 2. 关键考点

> 💡 **关键考点**：
> 1. 工作绩效信息流向：卖方数据 → 对照合同/计划 → 绩效信息 → 项目整体绩效。
> 2. 索赔处理顺序：核实事实 → 合同争议条款协商 → 调解/仲裁，不能跳步、不能单方行动。
> 3. 结束采购与结束项目的顺序：先关每个合同，再结束项目或阶段。

## 3. 常见考法

- 问控制采购各工具的归属，把"检查与审计"混进实施采购。
- 给索赔场景，判断正确处理步骤（先协商后仲裁）。
- 问工作绩效信息包含什么，把"团队人员绩效考核"当干扰项。
- 问结束采购与结束项目的关系，把"先结束项目再关合同"当干扰项。
- 激励类合同的付款计算：目标成本、目标费用、分摊比例、上限价代入。

常见坑：把沉没成本或团队内部考核算进采购绩效；认为合同签订后绝对不能变更；把采购审计等同财务审计。

## 4. 速记

口诀：**"先绩效审查，再检查审计，索赔按条款，谈判记档案；先关合同后结项。"**

| 流程 | 一句话理解 |
|---|---|
| 绩效审查 | 对着合同看卖方干得怎么样 |
| 检查与审计 | 买方派人核一核过程和成果 |
| 索赔管理 | 有争议按合同条款一步步来 |
| 结束采购 | 验收、结算、归档、关合同 |
