# 可行性研究

> 零基础导读：可行性研究回答"这个项目能不能做、值不值得做"。本节要掌握两件事：一是可行性研究从哪几个维度展开，二是财务评价里净现值、投资回收期怎么算——计算题年年有，公式必须背熟。

## 1. 概念与要点

**可行性研究**是在项目投资决策前，对拟建项目进行全面的技术经济分析与论证。它是立项管理的核心环节，成果是**可行性研究报告**。

**按研究深度分三个阶段**：**机会可行性研究**快速判断有没有机会，误差 ±30% 左右；**初步可行性研究**进一步筛选方案，误差 ±20% 左右；**详细可行性研究**全面深入论证，误差 ±10% 以内，作为投资决策依据。

**可行性研究的五个方面**（高频识记点）：

| 方面 | 回答的问题 | 举例 |
|---|---|---|
| 技术可行性 | 现有技术能否实现 | 团队技术栈、设备性能是否达标 |
| 经济可行性 | 投入产出是否划算 | 净现值、回收期、收益率 |
| 社会可行性 | 社会环境是否接受 | 就业影响、公众接受度 |
| 运行可行性 | 建成后能否正常运行 | 人员素质、维护条件、管理制度 |
| 法律可行性 | 是否合法合规 | 知识产权、数据安全、行业法规 |

**财务评价**是经济可行性的量化部分，常用指标：

**净现值 NPV**：把各年净现金流量按折现率折算到期初再求和。

$$NPV = \sum_{t=0}^{n} \frac{(CI - CO)_t}{(1 + i)^t}$$

其中 $CI$ 为现金流入，$CO$ 为现金流出，$i$ 为折现率。**NPV ≥ 0 项目可行**，越大越好。第 0 年的初始投资是流出，计入负数。

**投资回收期**：收回初始投资所需时间。**静态回收期**不考虑资金时间价值，按累计净现金流量为零的时点计算；若第 $k$ 年末累计仍为负、第 $k+1$ 年转正，则 $P_t = k + \frac{\text{未收回额}}{\text{下年净现金流量}}$。**动态回收期**用折现后流量计算，结果更长。

**投资收益率 ROI** = 年均利润 ÷ 投资总额 × 100%，越高越好；不考虑资金时间价值，常与 NPV 搭配。

**计算示范**：初始投资 100 万元，折现率 10%，第 1~3 年净收益 40、50、60 万元。NPV = −100 + 40/1.1 + 50/1.21 + 60/1.331 = 22.76 万元，可行。静态回收期 = 2 + 10/60 ≈ 2.17 年。

## 2. 关键考点

> 💡 **关键考点**：
> 1. 可行性五方面：技术、经济、社会、运行、法律，一个都不能少；别把"运行可行性"漏掉。
> 2. NPV 公式与代入：第 0 年投资取负，逐年用 $(1+i)^t$ 折现；NPV ≥ 0 可行。
> 3. 静态回收期的插值：$P_t = k + \frac{\text{未收回额}}{\text{下年净现金流量}}$，注意用累计净现金流量找转折年。

## 3. 常见考法

- 问可行性研究包含哪些方面，干扰项常塞进"进度可行性""合同可行性"等教材没有的说法。
- 直接给数字算 NPV，选项里放"忘记折现""投资取正号""折现次数少算一年"等陷阱。
- 算静态投资回收期，干扰项用总投资除以年均收益。
- 问三个研究阶段的误差范围与用途，考机会研究与详细可研的区别。

常见坑：投资流出忘记取负；折现年数把第 1 年算成 $(1+i)^0$；把 ROI 当成动态指标；把社会可行性理解成经济效益。

## 4. 速记

口诀：**"技经社运法，五性都要查；NPV 非负就可行，回收期里找转正。"**

| 指标 | 考虑时间价值 | 判据 |
|---|---|---|
| 净现值 NPV | 是 | ≥ 0 可行 |
| 静态回收期 | 否 | 越短越好 |
| 动态回收期 | 是 | 越短越好 |
| 投资收益率 ROI | 否 | 越高越好 |
