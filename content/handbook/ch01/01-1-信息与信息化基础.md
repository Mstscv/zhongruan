# 信息与信息化基础

> 零基础导读：先搞清楚"信息到底是什么、有哪些特性"，再看一堆软硬件凑成的**信息系统**怎么一步步建起来，最后记住国家搞**信息化**要靠哪六根支柱。这一节是全章的地基。

## 1. 概念与要点

**信息**是客观事物状态和运动特征的普遍形式。香农的经典定义：信息是用来消除随机不确定性的东西；维纳则说信息就是信息，既不是物质也不是能量。通俗讲，信息是消息里能帮人做判断的内容。

**信息的基本属性**（按教程口径重点记）：

| 属性 | 含义 | 一句话理解 |
|---|---|---|
| 依附性 | 必须依附于纸张、磁盘、声波等载体 | 没有载体的信息不存在 |
| 可传递性 | 可在时间与空间上转移扩散 | 转发邮件、网上发布 |
| 共享性 | 可被多方同时使用，一般不损耗 | 你看同一份新闻，我并不变少 |
| 可处理性 | 可被加工、整理、分析、提炼 | 汇总报表、数据挖掘 |
| 时效性 | 价值随时间推移可能下降 | 过期的股市行情没用 |
| 价值性 | 对不同接收者价值不同 | 同条招标信息对企业价值各异 |
| 可识别性 | 可通过感官或仪器识别 | 仪表读数、网页内容 |
| 真伪性 | 信息可能真也可能假 | 需要核验来源 |

区分三高频点：**共享性**是多用不减，**传递性**是从一处到另一处，**依附性**是必须有载体。

**信息系统**由相互联系的若干要素构成，能对信息进行采集、传输、处理、存储、管理、检索和输出。组成包括：计算机硬件、软件、数据及存储介质、通信系统、信息采集处理设备、规章制度和人员。可见信息系统不只是软件，还包括**人**和**制度**。

**信息系统生命周期**四个阶段：

1. **产生**：提出需求、可行性分析、立项；
2. **开发**：总体规划、系统分析、系统设计、系统实施、系统验收；
3. **运行**：投入使用并维护；
4. **消亡**：老化、更新换代或报废。

**信息化**是充分利用信息技术、开发利用信息资源、促进信息交流与知识共享、推动经济社会发展转型的历史过程。**信息化六要素**：

| 要素 | 地位 | 记法 |
|---|---|---|
| 信息技术应用 | 龙头、主阵地 | 把技术用起来 |
| 信息资源 | 核心任务、关键 | 有料可挖 |
| 信息网络 | 基础设施、必要手段 | 路要通 |
| 信息技术和产业 | 基础、自主能力 | 自己能造 |
| 信息化人才 | 成功之本 | 有人会干 |
| 信息化政策法规和标准规范 | 根本保障 | 有规矩成方圆 |

口诀：**"应用是龙头，资源是核心，网络是手段，产业是基础，人才是根本，政策是保障。"**

**两化融合**指信息化与工业化深度融合，是新型工业化道路的重要特征。

## 2. 关键考点

> 💡 **关键考点**：
> 1. 信息属性辨析：共享性"用不减"、传递性"会挪窝"、依附性"必有载体"，常混在一起考。
> 2. 信息系统生命周期四阶段及开发阶段的五个子阶段，常考"某项工作属于哪个阶段"。
> 3. 信息化六要素各自的地位（龙头/核心/手段/基础/根本/保障），常以"下列对应正确/错误的是"出题。

## 3. 常见考法

- 给一段生活或项目描述，问体现信息的哪种属性（如"一份报告发给多个部门使用"考共享性）。
- 把信息系统的组成窄化成"只有硬件和软件"，要求选出不正确说法。
- 问"系统验收""可行性研究"分别属于生命周期的哪个阶段。
- 六要素的地位张冠李戴，如把"信息技术应用"说成核心任务。

常见坑：认为共享性会导致信息减少；把信息系统理解为纯软件；混淆"产生"与"开发"阶段的工作。

## 4. 速记

六要素：**"应（用）是龙头，资（源）是核心，网（络）是手段，产（业）是基础，人（才）是根本，政（策）是保障。"**

生命周期：**"生（产生）—开（开发）—运（运行）—亡（消亡）"**，开发再记**"总分实收"**（总体规划、系统分析、系统设计、系统实施、系统验收）。
