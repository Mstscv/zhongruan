# 制定预算

> 零基础导读：估算只是"每项工作大概多少钱"。预算要把这些数字汇总、加上储备、排好时间，形成一份被批准的花钱计划——成本基准。谁在基准里、谁不在，是本章最爱考的辨析点。

## 1. 概念与要点

**制定预算**是汇总所有活动或工作包的成本估算，建立一个经批准的**成本基准**的过程。

**成本汇总**自下而上逐层进行：

活动成本估算 → 工作包 → 控制账户 → 摘要预算 → 项目预算

汇总时要加上两类储备，性质完全不同：

- **应急储备**：为已识别的风险预留，对应"已知-未知"，**计入成本基准**，项目经理可按风险情况动用。
- **管理储备**：为未识别的风险预留，对应"未知-未知"，**不计入成本基准**，但**计入项目预算**，动用需要管理层批准或走变更流程。

层级公式是必考点：

- 项目预算 = 成本基准 + 管理储备
- 成本基准 = 工作包估算合计 + 应急储备

**资金限制平衡**（资金平衡）：根据组织的资金拨付节奏调整支出计划，使成本基准的支出曲线与可获得的资金相匹配。项目资金需求来自成本基准加管理储备，常按投入时间呈阶梯式上升。

**成本基准**是经批准的按时间安排的项目预算，是测量和监控成本绩效的依据，通常以 S 形曲线展示。它不包含管理储备，这一点在判断题里反复出现。

## 2. 关键考点

> 💡 **关键考点**：
> 1. 层级包含关系：管理储备不在成本基准内，但在项目预算内；应急储备在基准内。动用管理储备须走变更，获批后计入基准。
> 2. 公式：项目预算 = 成本基准 + 管理储备；成本基准 = 活动合计 + 应急储备。
> 3. 成本汇总顺序：活动汇入工作包，工作包汇入控制账户，控制账户汇入摘要与项目预算。

## 3. 常见考法

- 给出各工作包金额、应急储备、管理储备，计算成本基准和项目预算。
- 问某笔预备金属于应急储备还是管理储备，看它对应已识别风险还是未识别风险。
- 问成本基准是否包含管理储备，或项目预算是否包含应急储备。
- 问资金限制平衡的作用，干扰项说它可以降低成本基准总额或增加管理储备。

常见坑：把管理储备算进成本基准；认为项目经理可自行动用管理储备；混淆汇总层级中工作包与控制账户的先后；把应急储备当作"节约下来的钱"。

## 4. 速记

口诀：**"估算汇总加应急，基准出炉；基准再加管理储备，才是预算；动用管理储备，须走变更。"**

| 概念 | 在基准内 | 在预算内 | 谁可动用 |
|---|---|---|---|
| 应急储备 | 是 | 是 | 项目经理 |
| 管理储备 | 否 | 是 | 管理层批准 |
| 成本基准 | — | 是 | 变更控制 |
