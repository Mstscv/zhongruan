# 制定项目管理计划

> 零基础导读：章程只说"项目可以干"，至于怎么干、按什么标准考核，全写在项目管理计划里。它是整个项目的总说明书和总考核基准，后面所有过程都围着它转。

## 1. 概念与要点

**制定项目管理计划**是定义、准备和协调所有子计划，并把它们整合为一份综合性的**项目管理计划**的过程。它不是一张简单的进度表，而是一整套"怎么管项目"的规则与基准集合。

**计划的结构可以分成两大块**：一块是**子计划**，即各知识领域的管理计划，如范围、需求、进度、成本、质量、资源、沟通、风险、采购、相关方管理计划；另一块是**基准与组件**，包括范围基准、进度基准、成本基准，以及变更管理计划、配置管理计划、绩效测量基准等。基准是经过批准、只能通过变更控制才能修改的计划版本。

**三大基准**是本节的核心：**范围基准**（范围说明书加 WBS 及 WBS 词典）、**进度基准**（经批准的进度模型）、**成本基准**（经批准的按时间段分配的项目预算）。三者合称**绩效测量基准**（PMB），是挣值分析时比较"计划值"的依据。注意：项目总预算 = 成本基准 + 管理储备，管理储备不在成本基准内，动用管理储备一般要走变更并影响基准。

**渐进明细**是计划的本质特征。项目早期信息不足，计划只能是粗框架；随着需求细化、风险识别推进，计划要不断滚动细化。计划不是"编一次就锁死"，但每一次对基准的修改都必须走**实施整体变更控制**，不能口头改、私下改。

**输入**包括项目章程、其他规划过程的输出、事业环境因素和组织过程资产。**工具**包括专家判断、数据收集、人际关系与团队技能、会议。**输出**就是项目管理计划本身，它一旦被批准，就成为执行、监控和收尾的依据。

区分一下几个易混概念：项目管理计划是"总文件"，子计划是它的组成部分；绩效测量基准是范围、进度、成本三基准的合称；管理储备应对"未知的未知"，成本基准内的应急储备应对"已识别的风险"。

## 2. 关键考点

> 💡 **关键考点**：
> 1. 项目管理计划 = 各子计划 + 三大基准 + 辅助组件（变更/配置管理计划等），是综合性文件。
> 2. 范围基准 = 范围说明书 + WBS + WBS 词典；三大基准合称绩效测量基准（PMB）。
> 3. 计划渐进明细，但基准的修改必须走变更控制，不能随意调整。
> 4. 项目总预算 = 成本基准 + 管理储备；管理储备不计入成本基准。

## 3. 常见考法

- 问"下列哪项属于项目管理计划的组成部分"，干扰项会混入项目文件（如风险登记册）或可交付成果。
- 考查绩效测量基准的构成：范围、进度、成本三基准，缺一不可，也不是"质量基准"。
- 考查范围基准的三件套：范围说明书、WBS、WBS 词典，注意 WBS 词典也算基准的一部分。
- 考查计划的修改规则：基准变更须审批，子计划可随项目推进细化，二者要求不同。
- 把管理储备算进成本基准，或把应急储备从成本基准中剔除，都是常见陷阱。

常见坑：以为项目管理计划就是进度计划；混淆储备与基准；认为计划一经批准永不更新。

## 4. 速记

口诀：**"计划一摞纸，三基是核心；范围说明书加 WBS 再加词典，进度成本来合体，合称绩效测量基准。"**

| 概念 | 包含内容 | 修改方式 |
|---|---|---|
| 范围基准 | 范围说明书、WBS、WBS 词典 | 变更控制 |
| 进度基准 | 经批准的进度模型 | 变更控制 |
| 成本基准 | 按时间段的预算（不含管理储备） | 变更控制 |
| 子计划 | 各知识领域"怎么管"的规则 | 可渐进明细 |
