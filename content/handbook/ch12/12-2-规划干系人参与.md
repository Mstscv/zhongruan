# 规划干系人参与

> 零基础导读：找到了人、摸清了脾气，还得提前想好"怎么跟他们打交道"。这一节就是制定与干系人互动的策略和行动，让关键人物愿意支持项目。

## 1. 概念与要点

**规划干系人参与**是根据干系人的需求、期望、利益和潜在影响，制定与其有效互动的方法的过程。它属于**规划过程组**，产出是**干系人参与计划**——这是项目管理计划的子计划，可随项目推进修订。

参与计划主要回答：对谁、采取什么策略、具体做哪些事、什么时候做、由谁做。例如对高权力高利益者安排定期汇报和联合决策，对不了解业务价值的用户安排培训和试用。

常用工具有：

- **标杆对照**：参考其他项目的干系人参与实践。
- **头脑风暴**：发散设计参与举措。
- **假设条件和制约因素分析**：明确预算、法规、组织文化等限制。
- **根本原因分析**：挖出抵触或不满的深层原因。
- **优先级排序**和**多标准决策分析**：在多个冲突诉求之间取舍。
- **干系人参与度评估矩阵**：本节的核心工具。

**干系人参与度评估矩阵**用 C 表示当前参与程度、D 表示期望参与程度，对比差距后设计提升路径。参与程度由低到高常分为：**不了解**、**中立**、**支持**、**领导**。不了解是对项目没概念；中立是知道了但不表态；支持是态度上站你这边；领导是主动参与并推动成功。

注意与沟通管理计划的分工：**沟通是手段，参与是目的**。沟通计划管信息怎么传，参与计划管关系怎么处。

## 2. 关键考点

> 💡 **关键考点**：
> 1. 干系人参与计划是规划干系人参与的输出，也是项目管理计划的组成部分。
> 2. 参与度评估矩阵的 C 是当前参与度、D 是期望参与度，差距就是管理空间。
> 3. 参与程度四档由低到高：不了解、中立、支持、领导；提升参与度要靠具体行动而不是空喊口号。

## 3. 常见考法

- 问规划干系人参与的输出是什么，与识别干系人的输出对比。
- 给 C 与 D 的落差情景，问应采取什么策略。
- 问参与度评估矩阵中 C、D 的含义，或某个档位的定义。
- 问参与计划与沟通管理计划的区别，强调手段与目的。

常见坑：把参与计划当成识别干系人的输出；把 C 当成成本、D 当成工期；把"中立"误认为"支持"。

## 4. 速记

口诀：**"C 看现在，D 看将来，差距补上才稳当"**；四档递进：**不了 → 中立 → 支持 → 领导**。
