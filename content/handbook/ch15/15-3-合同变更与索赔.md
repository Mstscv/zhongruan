# 合同变更与索赔

> 零基础导读：项目一变，合同跟着变；一方受了损失，就要按程序索赔。这一节记清"变更四步走"和"索赔六步走"，再弄懂时效，案例题就能踩到得分点。

## 1. 概念与要点

**合同变更**指合同成立后、尚未履行或未完全履行前，双方协商一致对原合同内容进行局部修改或补充。变更可由建设单位、承建单位或监理方提出，但均须经批准才生效。一般程序为：

**提出变更 → 审查变更 → 批准变更 → 修改合同**（签订补充协议或修改文本）

变更引起价款调整时，合同有适用单价的参照执行；没有适用单价的，按合理原则协商或参照类似单价确定。工程合同的变更一般应采用书面形式确认。

**索赔**是合同履行中一方因对方过错或非自身责任遭受损失，按合同程序要求补偿的正当权利，包括工期索赔与费用索赔。索赔不是扯皮，而是有严格程序的合同管理手段。常见流程：

1. **索赔意向通知**：索赔事件发生后在约定时限内（国际工程常为 **28 天**）发出；
2. **准备资料**：收集合同、往来函件、现场记录、票据等证据；
3. **提交索赔报告**：写明事件经过、合同依据、损失与工期计算、证据清单；
4. **对方答复**：被索赔方在约定期限内审查并答复；
5. **持续索赔**：事件持续发生的，每隔一定时间报送阶段性索赔报告，结束后报最终报告；
6. **仲裁或诉讼**：协商不成时按合同约定提请仲裁或诉讼，注意时效。

**索赔成立**的一般条件：事件造成了实际损失或额外支出；损失非索赔方自身过错造成；按合同程序及时通知并完成举证。谁主张谁举证，证据是索赔成败的关键。

**反索赔**是被索赔方对索赔要求的反驳、抗辩，或就对方违约提出自己的索赔，与索赔同样是正当权利。

索赔与变更常相伴而生：变更（如增加工作量、改变设计）是索赔的常见诱因，索赔是变更后果的救济途径。

## 2. 关键考点

> 💡 **关键考点**：
> 1. 变更程序排序：提出 → 审查 → 批准 → 修改合同，注意"修改"在最后。
> 2. 索赔第一步是发索赔意向通知（28 天内），不是停工、不是直接仲裁。
> 3. 持续索赔要阶段性报告；索赔成立要实际损失 + 非己方过错 + 及时通知举证。

## 3. 常见考法

- 考查变更或索赔程序的步骤排序，把"修改合同"或"意向通知"放在错误位置是常见陷阱。
- 给一个工期延误或窝工情境，判断索赔是否成立、可索赔工期还是费用。
- 考 28 天时限的适用对象（索赔意向通知），与其他程序节点的天数混淆。
- 计算误期赔偿或变更价款：注意合同约定的赔偿上限（如合同价的百分比）。

常见坑：把变更与索赔当成一回事；认为发了意向通知索赔就成立；持续索赔只报一次；逾期才主张权利导致失权。

## 4. 速记

口诀：**"变更四步：提、审、批、改；索赔六步：意、料、报、答、续、裁。"**

| 程序 | 起手式 | 时限/要点 |
|---|---|---|
| 合同变更 | 提出变更请求 | 批准后签补充协议 |
| 工程索赔 | 发索赔意向通知 | 事件后 28 天内 |
| 持续索赔 | 阶段性索赔报告 | 按约定间隔报送 |
| 争议解决 | 协商、调解 | 不成再仲裁或诉讼 |
