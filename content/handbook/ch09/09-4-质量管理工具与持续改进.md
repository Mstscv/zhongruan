# 质量管理工具与持续改进

> 零基础导读：质量管理离不开工具。这一节把最常用的七种基本质量工具一次讲清，重点是每种工具"长什么样、用来干什么"；再补上控制图的失控规则和 PDCA 持续改进循环，为计算题和识记题打底。

## 1. 概念与要点

**七种基本质量工具**是质量管理的经典工具箱，考试要求会认、会用、会区分适用场景：

| 工具 | 形态 | 适用场景 |
|---|---|---|
| 因果图 | 鱼骨/石川图 | 追溯问题的根本原因，按人机料法环分类 |
| 流程图 | 步骤与判断节点 | 展示过程步骤、决策点与流转路径 |
| 核查表 | 有组织的计数表 | 系统收集数据，便于后续分析 |
| 帕累托图 | 按频次降序的柱图 | 识别少数关键原因（约 20% 原因导致 80% 问题） |
| 直方图 | 频次柱状分布 | 显示数据分布形态，判断是否集中或离散 |
| 控制图 | 带上下限的折线 | 判断过程是否稳定、是否受控 |
| 散点图 | 两变量点阵 | 观察两个变量之间有无相关关系 |

**控制图**是本节重点。图上一般有三条线：中线为均值，**控制上限**（UCL）= 均值 + 3σ，**控制下限**（LCL）= 均值 − 3σ。注意区分**规格上限/下限**（USL/LSL，客户要求的公差范围，来自需求）与控制界限（过程固有波动，由数据算出）。

判断过程失控的常用规则是**七点法则**：连续七点落在均值同一侧，或连续七点持续上升/下降，说明过程存在异常原因，需要调查纠偏。点超出控制界限同样表示失控。

**持续改进**方面，最常考 **PDCA 循环**（戴明环）：Plan 计划、Do 执行、Check 检查、Act 处理，四步循环往复，每一轮都把遗留问题带入下一轮。**六西格玛**用 DMAIC（定义、测量、分析、改进、控制）框架追求极低缺陷率，其目标水平约为每百万机会 3.4 个缺陷。

## 2. 关键考点

> 💡 **关键考点**：
> 1. 七种工具的适用场景匹配：找根因用因果图，抓关键少数用帕累托图，看分布用直方图，看相关用散点图，看稳定性用控制图。
> 2. 控制图界限 = 均值 ± 3σ；七点法则（连续七点同侧或持续升降）判定失控；规格界限来自客户，控制界限来自数据。
> 3. PDCA 四步顺序与含义；六西格玛的 DMAIC 五个字母顺序。

## 3. 常见考法

- 给一句业务描述，选出对应的七种工具之一，尤爱考帕累托图与直方图的区分。
- 计算题：给定均值与标准差，算 UCL/LCL；或给一组点，按七点法则判断是否失控。
- 问规格界限与控制界限的区别：一个来自客户公差，一个来自过程数据。
- 问 PDCA 或 DMAIC 的字母顺序与含义，或问六西格玛的缺陷率目标。

常见坑：把帕累托图当成"看分布"的工具（那是直方图）；把规格上下限误当成控制上下限；把 PDCA 的 Check 理解成"检查产品合格"，实为对照计划找偏差。

## 4. 速记
